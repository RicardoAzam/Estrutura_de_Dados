# Estrutura_de_Dados
Este repositório foi criado para aplicacao de estruturas de dados e métodos de ordenacao em linguagem C. É constituido de diversos exercicios de pilha, lista, fila e arvore, e 3 projetos. O projeto "Tarefa" é sobre testes de velocidade de ordenacao de um conjunto de dados alto. "Projeto 1" consiste em um sistema operacional de uma veterinária, utilizando o conceito de Fila. "Projeto 2" é um sistema operacional de vendas, utilizando o conceito de arvore.
